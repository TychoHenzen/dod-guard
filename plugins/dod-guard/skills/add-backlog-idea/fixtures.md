# Context preservation fixture

| Input | Expected capture record |
| --- | --- |
| Two features share the constraint "preserve cited examples", feature A has decision "use existing issues", and a final supplied detail fits neither feature. | Both issues retain the shared constraint; A retains the supplied decision in `## Context`; show the final detail as an explicit unresolved remainder. With a user present, ask where it belongs inside the single batched round. When another skill invoked this one or no user is present, ask nothing and report it as the unresolved remainder for the caller to decide. |
| A user invokes the skill directly in an interactive session with "make exports better", which states no outcome. | One batched round: every question in one turn, 3 or 4 options each with the first marked (Recommended), an `Other` option, a Low/Medium/High label per question ordered High to Low, and a reply format. The answers are kept word for word under `## Context`; unanswered points go under `## Open questions`. No second round, and no codebase reading. |
| `dod-guard:quick-pbi` or `dod-guard:goal-sdlc` invokes the skill with the text "make exports better", or no user is present. | Nothing is asked. The issue is created with the text as `## Idea` and each open point under `## Open questions`. |
| An earlier run created issue "Add stale-asset report" and stopped before the Project add. The same request runs again. | The duplicate search finds the open exact-title match. No second issue is created and the match is not edited. Steps 2 and 3 run for it, and the final report lists `existing issue #N`. |
| A request has two parts and it is unclear whether they are separate outcomes, and no user is asked. One supplied detail belongs to the feature but has no decision. | When no user is present, or the round leaves the split unclear, one issue is created that holds both parts. The undecided detail is under that issue's `## Open questions`. Nothing is dropped. |
| The search finds an open issue with the same title that is already on the Project in `Todo`. | It is reported as `existing issue #N`. It is not edited, closed, or moved, and no second issue is created. |
| A user is asked the batched round and replies with nothing, or declines to answer. | No second round and no codebase reading. Every open point goes under `## Open questions`. The split falls back to one issue that holds all of the text. Nothing is dropped. The final report maps the one issue to its URL and lists no unresolved remainder. |
| A user answers part of the round and leaves the split unsettled. | No second round. The answers are kept word for word under `## Context`. Each unanswered point goes under `## Open questions`. One issue is created that holds all of the text. The final report maps the one issue to its URL and lists no unresolved remainder. |
| A user answers the split question and leaves the unmappable text unanswered. | The settled split is honored and its answers stay under `## Context`. The text that fits no feature stays the unresolved remainder in the final report and is not placed under `## Open questions`. No second round. |
