## Why

The six `opsx:*` skills in `.claude/skills/` were generated by the OpenSpec CLI. They are generic workflows that do not know about dod-guard's scenario-coverage pipeline, `steps.json` execution plans, `dod-guard cover`, the `dod-guard-spec-driven` schema, or the verification gate. The user has to hold the mental model of when to use `/opsx:apply` versus `/dod-guard:step-by-step`, or how `/opsx:propose` relates to `/dod-guard:interview`. The generated skills work but do not integrate with the verification layer that makes this monorepo's workflow distinct.

## What Changes

- Replace all six generated skills in `.claude/skills/openspec-*` with dod-guard-aware versions under `packages/dod-guard/skills/`:
  - `opsx-explore` - thinking partner that knows about existing specs, capability groups, and when to hand off to `/interview` or `/opsx:propose`
  - `opsx-propose` - creates changes using the `dod-guard-spec-driven` schema by default, generates the `steps` artifact via `dod-guard steps`, and validates with `openspec validate --strict`
  - `opsx-apply` - routes through `/dod-guard:step-by-step` for `steps.json` execution rather than implementing tasks directly, runs `dod-guard cover` before archiving
  - `opsx-update` - revises change artifacts and regenerates `steps.json` when tasks change
  - `opsx-sync` - syncs delta specs to main specs (same as generated version, but under dod-guard ownership)
  - `opsx-archive` - runs `dod-guard cover` as a gate before archiving, fails on regression
- Delete the six generated `.claude/skills/openspec-*` directories
- Update `packages/dod-guard/.claude-plugin/marketplace.json` to list the new skills

## Capabilities

### New Capabilities
- `dod-guard/opsx-explore`: Thinking partner skill that knows about existing specs, capability groups, scenario coverage, and when to hand off to `/interview` or `/opsx:propose`.
- `dod-guard/opsx-propose`: Skill that creates OpenSpec changes with the `dod-guard-spec-driven` schema, generates `steps.json` via `dod-guard steps`, and validates the result.
- `dod-guard/opsx-apply`: Skill that routes implementation through `/dod-guard:step-by-step` for `steps.json` execution and runs `dod-guard cover` before archiving.
- `dod-guard/opsx-update`: Skill that revises change artifacts and regenerates `steps.json` when tasks change.
- `dod-guard/opsx-sync`: Skill that syncs delta specs from a change to main specs with intelligent merging.
- `dod-guard/opsx-archive`: Skill that gates archiving on `dod-guard cover` passing and runs `openspec archive` only when coverage holds.

### Modified Capabilities

None.

## Impact

- Six new SKILL.md files under `packages/dod-guard/skills/`
- Six deleted directories under `.claude/skills/openspec-*`
- `packages/dod-guard/.claude-plugin/marketplace.json` updated with new skill count and descriptions
- The `opsx:*` slash-command aliases continue to work because the SKILL.md `name` field matches
- `validate-plugins.mjs` and `check-skill-hygiene.mjs` run against the new skill directories
